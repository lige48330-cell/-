AGENT ENGINEERING METHOD

Agent 不是聊天框，是一条有人可接管的工作流

交互设计

任务成形 · 把自然语言目标变成范围、输入和成功标准。

上下文确认 · 展示引用资料、约束和待确认信息，减少黑盒感。

工具行动 · 明确调用哪个工具、会改变什么、是否需要人批准。

结果反馈 · 输出差异、证据、失败原因和下一步，而不是只给结论。

交接复盘 · 保留任务记录，让人和下一个 Agent 都能继续工作。

工程系统

Context contract · 项目背景、边界、证据和输出格式先结构化。

Skill / registry · 能力入口、版本、适用范围和责任边界可发现。

Tool semantics · 声明工具适用范围、确认点与人工接管边界。

Offline checks · 用测试、日志、质量检查和复盘记录追踪结果。

解决的问题 · 减少上下文丢失、任务误解、结果不可复核和团队无法接手。
