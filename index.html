CASE 01 · IoT / .NET 8 / uni-app

ESP32 IoT 平台

面向智能消毒除臭设备的三端监管平台，覆盖设备固件、云平台与微信小程序。

01 · 固件与设备

PlatformIO / Arduino 框架，含自动与手动模式、串口配置、NVS 存储与 MQTT 上报。

02 · 云平台

.NET 8 + EF Core Sqlite，JWT 认证，四角色权限，工单报修，报表与自研 MQTT Broker。

03 · 小程序

uni-app 多角色入口（监管 / 管理 / 安装 / 养殖），Vue 3 + Pinia 状态管理。

04 · 证据

后端隔离构建 0 警告 0 错误；数据库迁移脚本 V1-V17 完整；部署文档齐全。设备端到端联调进行中。

证据等级：推进中 · 云端能力已验证，设备联调待完成。

  • ESP32 固件
  • .NET 8
  • MQTT Broker
  • uni-app

CASE 02 · Python / CLI / Quality Gate

AI Supervisor

一个把 AI Agent 输出与设计规范、实施计划对照审查的命令行工具实验。

01 · Review

对照规范与计划输出人工可读的审查报告。

02 · Guard

将审查结果作为 CI 风格门禁。

03 · Hook 与 Doctor

提供工具链接入与监督就绪度诊断，配套 MCP server。

04 · 证据

pytest 运行 93 项测试，全部通过。CLI 四命令（review / guard / hook / doctor）可用于监督流程。

证据等级：工具化实验 · 证明工具化思路可行，不承诺全自动监督。

  • Python CLI
  • Spec / Plan
  • MCP Server
  • pytest 93

CASE 03 · Vue / uni-app / Express / Prisma

智慧水产养殖应用套件

由 H5、微信小程序壳与 Node.js 服务组成的三端全栈原型，覆盖养殖、物料、设备和告警模块。

01 · H5 端

Vue 3 + Vant 4 + Pinia，覆盖登录、工作台、养殖、物料、设备、报警与个人中心。

02 · 小程序壳

uni-app 壳子通过 web-view 加载 H5，以 postMessage 桥接切换 Tab 与扫码。

03 · Node 服务

Express + Prisma + SQLite，JWT 认证，统一响应格式，幂等与全局错误处理。

04 · 证据

API 测试 12 项全部通过；Mock 与真实双模式；本地可完整启动链路。

证据等级：可运行全栈原型 · 说明技术闭环可行，不等同于真实生产运营。

  • Vue 3
  • uni-app
  • Express
  • Prisma
