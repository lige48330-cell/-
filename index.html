  • 完成设备端、云端与小程序端基础联调，验证前端操作到硬件响应的闭环。

交付内容

  • 远程开关控制原型
  • 小程序控制页面
  • ESP32与继电器控制链路
  • MQTT/HTTP通信验证

  • 使用自定义 Skill 固化简历摘要、ATS 检查、cover letter 生成和面试准备流程，加入中文内容和本土化提示
  • 以本地 SQLite、脚本和 Markdown 证据保存可复盘的操作链路，适配中国招聘流程

我负责什么

  • 学习并改造适配求职自动化 pipeline：职位解析、评分、报告生成、PDF输出、状态追踪，针对中国招聘平台做了本地化调整。
  • 改造适配自动化脚本：offer评估、CV生成、portal扫描、follow-up管理，增加中文支持和本地平台适配。
  • 维护数据层：applications tracker、pipeline inbox、scan history、profile，使其适用于中国求职场景。

  • 自定义 Codex Skill
