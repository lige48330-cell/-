# digital-aquaculture-prototype 代码学习指南

本指南用于系统学习这个 Vue 3 + TypeScript + Vite 原型的代码结构，不是运行说明或页面介绍。目标是能从入口追到路由、页面模块、状态数据、可视化组件和 mock 数据。

## 学习目标

完成后应能说明：应用如何启动，路由如何切换到首页和水质模块，水产监控数据从 `src/mock/` 与 `src/store/` 如何进入组件，以及新增一个监控卡片或趋势图时要改哪些文件。

## 建立基线

先读 `package.json`，确认脚本只有 `dev`、`build`、`preview`。本地验证优先使用：

```bash
npm install
npm run build
npm run dev
```

`npm run build` 会先执行 `vue-tsc -b`，所以它比单纯启动 dev server 更适合作为学习前后的基线。

## 推荐阅读路径

1. 入口层：读 `index.html`、`src/main.ts`、`src/App.vue`，确认 Vue 应用挂载点和全局样式。
2. 路由层：读 `src/router/index.ts`，画出 `/`、首页模块、水质模块之间的页面映射。
3. 框架层：读 `src/layout/Layout.vue`、`src/layout/Header.vue`、`src/layout/Sidebar.vue`，理解整体壳、导航和页面插槽。
4. 首页切片：读 `src/modules/home/index.vue`，再顺着组件引用去看 `src/components/StatGrid.vue`、`src/components/StatCard.vue`、`src/components/AlarmBar.vue`。
5. 水质切片：读 `src/modules/water-quality/index.vue`，再看 `src/store/water.ts` 与 `src/mock/water.ts`。
6. 可视化组件：读 `src/components/TrendChart.vue`、`src/components/DataTable.vue`、`src/components/AlarmTable.vue`、`src/components/SceneView.vue`、`src/components/ActionPanel.vue`，区分展示组件和业务状态。

## 动手练习

- 在 `src/mock/water.ts` 增加一条模拟水质指标，观察 `src/store/water.ts` 和对应组件是否需要调整。
- 给 `src/components/StatGrid.vue` 增加一个只读统计项，确保数据来源仍来自页面或 store，而不是组件内部硬编码业务状态。
- 修改一条报警 mock 数据后运行 `npm run build`，确认类型和打包仍通过。

## 常见陷阱

- `README.md` 仍是 Vite 模板内容，不要把它当成项目架构说明。
- `public/images/fish-pond.jpg` 和 `public/icons/logo.png` 是视觉资产，业务流仍以 `src/` 下的模块、store、mock 为准。
- 组件多为展示型，新增业务状态应优先看页面模块和 store，而不是直接塞进图表组件。

## 完成标准

- 能画出 `main.ts -> App.vue -> router -> layout -> modules/* -> components` 的链路。
- 能解释水质数据从 `src/mock/water.ts` 到页面组件的传递方式。
- 能做一个小改动并用 `npm run build` 验证。
