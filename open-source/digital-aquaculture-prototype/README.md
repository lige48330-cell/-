# Digital Aquaculture Prototype

一个以水质、气象、设备、视频、养殖记录和报表分析为核心的数字水产工作台原型。

## 这个仓库展示什么

- 把水产业务对象拆成可讨论的页面、状态和数据视图
- Vue 3 + TypeScript + Pinia + ECharts 的前端实现
- 面向需求评审的 mock 数据和交互闭环
- 从业务模型到信息架构、组件和图表的原型交付能力

## 本地运行

```bash
npm install
npm run dev
```

构建检查：

```bash
npm run build
```

## 公开边界

仓库只包含个人原型和模拟数据，不包含公司项目源码、客户资料、真实设备数据或生产配置。
