CODEXCONT · REFERENCE 01

流式阅读速查

在学习 incremental_sse() 与 fold_stream() 时随手查阅。

术语在本项目中的准确含义不要误解为
HTTP chunk网络层本次交给 aiter_bytes() 的一段任意字节。完整 SSE event 或完整 JSON。
SSE event由空行终止的一组文本行；本项目取其中 data: 行并解析 JSON。恰好等于一个 HTTP chunk。
DONEdata: [DONE] 的内部 sentinel；表示流结束标记已出现。最终业务状态。真正的完成／失败由 terminal event 判断。
terminal eventresponse.completed、response.failed 或 response.incomplete。[DONE] 本身。
reasoning可以实时转发、并在续写时可重放的输出项。最终给用户的可提交答案。
暂定输出本轮 message 或 function_call；在 out_buffer 中等待终态。已经可以安全下发的答案。
提交边界收到终态且决定不再续写后，调用 _flush_entry() 的时刻。模型刚首次发出 message delta 的时刻。
replay_tail之前截断轮的 completed reasoning 加续写 marker；构成后续轮 input 的尾部。上一轮全部输出。
一条规则：先问“这是什么层的边界？”——chunk、SSE event、输出项、response terminal。很多流式 bug 都是把其中两层混在一起。
来源：本仓库 middleware/sse.py 与 middleware/proxy.py；延伸验证见 MDN SSE 文档。
