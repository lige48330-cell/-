# 专业小程序开发者展示小程序：代码学习指南

这是一条理解当前静态 uni-app 应用代码的学习路径，不替代 README 的运行说明，也不扩展为后端或接口设计文档。

## 适用读者与学习成果

适合熟悉 JavaScript/Vue 基础、准备维护此展示型小程序的开发者。完成后应能说明应用如何启动、页面如何注册、首页状态如何驱动模板、咨询交互为何不保存或上传数据，并能分别构建 H5 和微信小程序产物。

## 0. 建立可验证的起点

`package.json` 的脚本说明本项目使用 uni-app 与 Vue 3：

```bash
npm install
npm run build:h5
npm run build:mp-weixin
```

开发时可运行 `npm run dev:h5`；它会持续运行，适合在浏览器中观察页面。`build:h5` 和 `build:mp-weixin` 是一次性验证，已生成的输出位于 `dist/build/`，不应作为学习或修改的源码。

**动手验证：** 成功构建后，确认 `dist/build/h5/` 与 `dist/build/mp-weixin/` 都存在；若依赖或构建失败，先记录错误，不要直接修改 `src/` 来“修复”环境问题。

## 1. 从构建配置到应用入口

按顺序阅读：

1. `package.json`：四个 H5/微信开发与构建脚本以及 `@dcloudio`、Vue、Vite 依赖。
2. `vite.config.js`：以 `@dcloudio/vite-plugin-uni` 注册 uni-app 构建插件。
3. `index.html`：H5 容器入口；它只服务 H5 目标。
4. `src/main.js`：通过 Vue 的 `createSSRApp(App)` 建立应用，并返回 `{ app }`。
5. `src/App.vue`：当前仅提供全局页面样式。

**动手验证：** 从 `src/main.js` 的 `App` 导入跳转到 `src/App.vue`，然后运行 `npm run build:h5`。说明该文件路径是源码入口，而不是 `dist/build/h5/` 中编译后的 JavaScript。

## 2. 先读页面注册与平台元数据

继续阅读两个 JSON 文件：

- `src/pages.json`：当前只注册 `pages/index/index`，并设置导航栏标题与全局导航栏/背景样式。
- `src/manifest.json`：应用名、版本和 `mp-weixin` 配置；其中 `appid` 为空，微信端配置与页面业务逻辑分离。

**动手验证：** 根据 `pages.json` 找到 `src/pages/index/index.vue`。修改前先说明：若新增页面，需要同时有页面文件和 `pages.json` 注册；仅新增一个 `.vue` 文件不会自动成为路由页面。

## 3. 按“状态 → 事件 → 模板 → 样式”读首页

首页全部源码在 `src/pages/index/index.vue`，建议不要按视觉区域从头扫到尾，而按以下层次阅读：

1. `<script setup>`：`projectTypes`、`budgetRanges`、`services`、`solutions`、`steps` 是静态展示数据；`form` 用 Vue 的 `reactive` 保存当前页面内的项目类型、预算与需求描述。
2. 事件函数：`updateProjectType` 和 `updateBudget` 从 picker 事件取值并更新 `form`；`submitConsultation` 只调用 `uni.showModal` 显示提示。
3. `<template>`：`v-for` 将静态数组渲染为服务卡片、方案标签和流程；两个 `picker` 绑定事件，`textarea` 用 `v-model` 绑定 `form.description`，按钮调用 `submitConsultation`。
4. `<style scoped>`：页面、卡片、网格、时间线和表单的局部样式；全局 `page` 样式在 `App.vue`。

**动手验证：** 在 H5 开发预览中选择一个项目类型、预算并输入描述，点击“生成咨询提示”。应显示本地提示；刷新后输入消失，这与 `form` 仅在内存中创建且没有存储/网络调用一致。

## 4. 理解当前隐私和功能边界

README 与 `src/pages/index/index.vue` 的实现一致：当前版本不登录、不连接后端 API、不使用云开发或数据库，咨询信息只用于当前页面交互。把这个边界作为阅读约束：`submitConsultation` 的结束点是 `uni.showModal`，而非网络请求。

**动手验证：** 在 `src/` 中搜索 `uni.request`、`wx.request`、`wx.login`、`getPhoneNumber`、`getUserProfile`、`cloud.database` 与 `cloud.callFunction`。当前源码不应包含这些调用；同时确认 `index.vue` 中的隐私说明与 `submitConsultation` 的提示文本没有承诺保存或提交数据。

## 5. 平台构建产物的阅读边界

同一份 `src/` 同时用于 H5 与微信小程序：`npm run build:h5` 生成 H5 输出，`npm run build:mp-weixin` 生成微信小程序输出。`project.config.json` 与 `project.private.config.json` 位于根目录，供微信开发者工具项目配置使用；先理解源码再查看它们。不要编辑 `dist/`，它是构建结果，下次构建会重新生成。

**动手验证：** 依次执行两条构建命令，比较 `dist/build/h5/` 与 `dist/build/mp-weixin/` 中的输出结构；只以 `src/` 的改动作为下一次构建的输入。

## 常见阅读陷阱

- 这是单页展示应用：当前路由来源于 `src/pages.json`，不是传统 Vue Router 配置。
- `index.html` 只对应 H5；微信端的运行形态由 uni-app 构建及 `manifest.json` 的 `mp-weixin` 配置决定。
- `form.description` 的 `v-model` 只是本地响应式状态，不等于已保存的数据。
- `dist/` 是生成目录，`node_modules/` 是依赖目录；两者都不是业务源码。
- 页面包含“后端 API”“IoT 对接”等服务介绍文字，但当前实现没有这些业务接口；不要把展示文案误读为已经实现的功能。
- 联系方式文本仍是占位内容；学习交互时不要误把它当作配置中心或用户数据。

## 完成标准

- 能从 `package.json` 的目标脚本说明代码如何经过 `vite.config.js`、`src/main.js`、`src/App.vue` 到 `src/pages/index/index.vue`。
- 能解释 `pages.json`、`manifest.json` 与首页 `.vue` 分别负责什么。
- 能在不新增后端的前提下，准确指出项目类型/预算/描述从事件到界面提示的本地数据流。
- 已成功执行 `npm run build:h5` 和 `npm run build:mp-weixin`，或明确记录被环境阻塞的命令与错误。
- 能区分 `src/`、`dist/` 和 `node_modules/`，并在修改任何页面前确认是否需要同步 `pages.json`。
