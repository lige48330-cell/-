# Industrial Monitor Prototype

一个以设备时间轴、AI 概率分析、激光厚度图和视频时间轴为核心的工业监控交互原型。

## 这个仓库展示什么

- 复杂设备状态的分层信息架构
- Vue 3 + ECharts + Element Plus 的前端组合
- 时间轴、趋势图和视频状态的联动表达
- 使用 mock 数据验证需求和交互，不连接生产设备

## 本地运行

```bash
npm install
npm run dev
```

构建检查：

```bash
npm run build
```

## 公开边界

仓库只包含个人原型和模拟数据，不包含公司项目源码、客户资料、设备地址或生产凭据。
