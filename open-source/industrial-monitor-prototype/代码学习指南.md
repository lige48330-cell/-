# industrial-monitor 代码学习指南

本指南用于系统学习这个 Vue 3 + Vite 工业监控仪表板原型的代码，不是普通 README。重点是理解单页入口、监控大屏页面、图表组件、时间线组件和 mock 数据之间的关系。

## 学习目标

完成后应能说明：`src/main.js` 如何启动应用，`src/App.vue` 和 `src/views/IndustrialMonitor.vue` 谁负责页面骨架，设备、视频、图表 mock 数据分别喂给哪些组件，以及新增一个监控区域时的修改路径。

## 建立基线

先读 `package.json`，项目脚本为：

```bash
npm install
npm run dev
npm run build
```

没有发现专门测试脚本，因此 `npm run build` 是最低限度验证。

## 推荐阅读路径

1. 启动入口：读 `index.html`、`src/main.js`、`src/App.vue`。
2. 主页面：读 `src/views/IndustrialMonitor.vue`，把页面区域、组件引用、mock 数据导入关系标出来。
3. 数据来源：读 `src/mock/device.js`、`src/mock/video.js`、`src/mock/chart.js`，确认数据形状。
4. 设备时间线：读 `src/components/DeviceTimeline.vue`，理解设备事件如何展示。
5. 视频时间线：读 `src/components/VideoTimeline.vue` 与 `src/components/TimeQuery.vue`，理解查询状态和展示边界。
6. 图表组件：读 `src/components/AIProbabilityChart.vue` 和 `src/components/LaserThicknessChart.vue`，确认图表输入字段、样式和刷新方式。
7. 旧实现对照：只在需要时看 `src/Appnew.vue`、`src/components/备份/`，不要先从备份文件学习主链路。

## 动手练习

- 在 `src/mock/device.js` 增加一个设备状态，追踪它是否被 `src/views/IndustrialMonitor.vue` 和 `src/components/DeviceTimeline.vue` 正确消费。
- 修改 `src/mock/chart.js` 中一组趋势数据，确认两个图表组件的输入字段是否一致。
- 用 `npm run build` 做验证；若只是样式调整，也要至少启动 `npm run dev` 浏览主页面。

## 常见陷阱

- `README.md` 是默认 Vite 模板，不代表项目真实结构。
- `src/Appnew.vue` 和 `src/components/备份/` 容易误导阅读顺序，先以 `src/main.js -> src/App.vue -> src/views/IndustrialMonitor.vue` 为准。
- mock 数据是当前业务事实来源；没有后端 API 层时，不要假设存在请求服务。

## 完成标准

- 能说明三类 mock 数据分别进入哪些组件。
- 能定位一次时间查询或图表展示从页面到组件的代码路径。
- 能做一个小数据结构改动，并确认构建通过。
