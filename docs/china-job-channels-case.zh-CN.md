# 有界数据流水线 · 脱敏能力卡

## 一句话

把浏览器采集、规范化、预览、记录真源和离线检查组织成一条有边界、可复盘的全栈自动化链路。

## 系统触点

- Node 本地 Dashboard：提供启动、记录接收和静态预览入口。
- Python 采集器：处理受控的浏览器采集和离线解析。
- 规范化层：把原始结果收敛为稳定 JSONL 结构，保留来源和状态。
- 记录真源：区分已确认结果与尝试，避免把一次点击误报为完成。
- 验证：`npm run check` 覆盖 JavaScript smoke、接口、规范化和 Python 离线测试。

## 可核对结果

- 本机离线检查通过：JavaScript smoke / E2E 与 Python 测试合计 57 个用例。
- 批次、扫描范围和结果状态都有上限；实时浏览器行为仍需要人工受控验证。

## FDE 价值

我关注的不是“自动点得多快”，而是把输入、状态、来源、失败和恢复路径做成团队能接手的协议。这类经验可以迁移到 Agent 工具调用、数据摄取和运营后台。

## 公开边界

原始工程依赖登录态和第三方页面，不公开源码、账号、会话数据或抓取结果。本页只展示架构判断、离线证据和边界。
