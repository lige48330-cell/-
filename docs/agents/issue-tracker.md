# Issue tracker: GitHub

Issues and PRDs for this repository live in GitHub Issues. Use the `gh` CLI when it is available.

## Conventions

- Create an issue with `gh issue create --title "..." --body "..."`.
- Read an issue with `gh issue view <number> --comments`.
- Apply labels with `gh issue edit <number> --add-label <label>`.

## Pull requests as a request surface

PRs are not a request surface for this repository. Do not add external PRs to the triage flow.

## Publishing a PRD

Create a GitHub issue and apply the `ready-for-agent` label.
