## Agent skills

### Issue tracker

GitHub Issues is the sole task tracker. External pull requests are not a request surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Use `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository. Read root `CONTEXT.md` and relevant records in `docs/adr/` when they exist. See `docs/agents/domain.md`.
