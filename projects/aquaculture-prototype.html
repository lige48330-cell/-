Vue / uni-app / Express / Prisma

智慧水产养殖应用套件

面向水产养殖基地的三端全栈原型：H5 工作台、微信小程序壳与 Node.js 服务，覆盖养殖、物料、设备和告警模块。

证据等级：可运行全栈原型
aquaculture-suite

01 / 系统组成

三个端协同推进

01

H5 端

Vue 3 + Vant 4 + Pinia，覆盖登录、工作台、养殖、物料、设备、报警与个人中心。

02

小程序壳

uni-app 壳子通过 web-view 加载 H5，以 postMessage 桥接切换 Tab 与扫码。

03

Node 服务

Express + Prisma + SQLite，JWT 认证，统一响应格式，幂等与全局错误处理。

02 / 诚实边界

可运行的闭环，非生产系统

  1. 可复现API 层支持 Mock 与真实双模式，本地可启动完整链路。
  2. 测试证据2026-08-07：服务端 API 测试 12 项全部通过。
  3. 原型定位说明技术闭环可行，不等同于真实生产运营环境。
  4. 示意图架构图用于解释设计，不伪装成运行截图。
